# 🍅🐒 Monkey Business (Unity 2D)

A fun, physics-based arcade game inspired by classic projectile mechanics—where **tomatoes take on mischievous monkeys** in a chaotic battle of precision and destruction.

---

## 🎮 Overview

**Monkey Business** is a 2D physics-driven game where players launch tomatoes to knock down structures and defeat monkeys hiding within them. The goal is to clear each setup using limited shots while maximizing destruction and score.

Built with a focus on **core gameplay systems, clean scripting, and game feel**, this project explores how simple mechanics can be enhanced with feedback and polish.

---

## ✨ Features

* 🍅 **Projectile Mechanics**
  Drag, aim, and launch tomatoes with satisfying physics-based movement.

* 🐒 **Dynamic Targets**
  Monkeys react to collisions and can be eliminated through direct hits or collapsing structures.

* 🧱 **Destructible Structures**
  Breakable objects create emergent gameplay and varied outcomes.

* 🎯 **Score System**
  Earn points by destroying objects and eliminating targets efficiently.

* 🔊 **Improved Audio System**
  Controlled sound playback with volume balancing, cooldowns, and background music.

* 💥 **Juice & Feedback**

  * Explosion effects
  * Sound effects with pitch variation
  * Responsive interactions

---

## 🧠 What This Project Demonstrates

* Unity 2D fundamentals (**Rigidbody2D, Collisions, Prefabs**)
* Input handling and projectile physics
* Basic game loop design (aim → shoot → resolve → score)
* Audio management and sound balancing
* Debugging and iterative development
* Creating “game feel” using simple effects

---

## 🎯 Controls

* **Click + Drag** → Aim
* **Release** → Launch tomato
